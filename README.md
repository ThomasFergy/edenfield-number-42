# Edenfield Number 42

Everything for Edenfield Number 42, a family-run guest house in North Shore, Blackpool.

| Folder | What it is |
| --- | --- |
| [`website/`](website/) | The hotel website (Vite + React + TypeScript) |
| [`menus/`](menus/) | Print-ready breakfast menus typeset in LaTeX |

Both share the same navy-and-gold look.

## Website

```sh
cd website && npm install && npm run dev
```

See [`website/README.md`](website/README.md).

## Menus

```sh
cd menus && ./build.sh
```

See [`menus/README.md`](menus/README.md).
