# Photos

Images in this folder are picked up automatically by file name (`.jpg`, `.jpeg`, `.png`, `.webp` or `.avif`).
A missing file falls back to an on-brand placeholder, so photos can be swapped one at a time.

| File | Where it appears | Shape |
| --- | --- | --- |
| `hero` | Top of the page, beside the title | Portrait (3:4): the frontage with the gold "Number 42" sign |
| `welcome` | Welcome section | Portrait crop (4:5) |
| `breakfast` | Breakfast section | Portrait crop (4:5) |
| `room-1`, `room-2`, `room-3`, `bathroom` | Photo strip in the Rooms section | Portrait crop (3:4) |

## Current photos

The current images were saved from the property's Booking.com gallery at roughly 576–1024 px.
They are good enough to launch with but soft on large or high-DPI screens. When you can, replace them
with the originals from the hosts (same file names), exported at ~2000 px on the long edge,
JPEG quality ~80, under ~400 KB each.

Only use photos the hotel owns or has permission to use.
