# Photos

Drop the hotel's own photos here, using these exact file names (`.jpg`, `.jpeg`, `.png`, `.webp` or `.avif`).
Anything missing falls back to an on-brand placeholder, so you can add them one at a time.

| File | Where it appears | Suggested shape |
| --- | --- | --- |
| `hero` | Full-screen background at the top | Landscape, the red-brick frontage with the gold "Number 42" sign |
| `welcome` | Welcome section | Portrait (4:5) |
| `room-twin` | Standard Twin Room card | Landscape (4:3) |
| `room-double` | Double Room | Landscape (4:3) |
| `room-deluxe-double` | Deluxe Double Room | Landscape (4:3) |
| `room-deluxe-king` | Deluxe King Room | Landscape (4:3) |
| `room-king-suite` | King Suite | Landscape (4:3) |
| `room-deluxe-king-suite` | Deluxe King Suite | Landscape (4:3) |
| `breakfast` | Breakfast section | Portrait (4:5) |

Tips: export at about 2000px on the long edge, JPEG quality ~80, and keep each file under ~400 KB.
Only use photos the hotel owns or has permission to use.
